# X external links and audience strategy

Researched September 8, 2026. User priority: build a following on X, not maximize website referrals.

## Evidence

Buffer's October 14, 2025 study covers 18.8 million posts from 71,000 accounts. Link posts showed lower engagement than text, image, and video posts, including among Premium accounts. This is observational evidence. Content, audience, account characteristics, and posting behavior can confound the comparison. Zero median engagement for some observations does not mean every link received zero impressions. Historical data does not prove a universal current penalty.

Source: https://buffer.com/resources/links-on-x/

X's published ranking repository describes predictions for engagement, link clicks, attention, author follows, and negative feedback, with additional ranking and visibility systems. Some rules are omitted and configuration can change. Its public description does not establish a universal fixed external-link penalty, nor prove that none exists.

Source: https://github.com/xai-org/x-algorithm

X supports links and images inside native Articles. The materials reviewed do not establish that primary-source citations inside an Article have the same distribution effect as a timeline post sending readers to an external website. Do not conflate these cases.

Source: https://help.x.com/en/using-x/articles

## Black Scarab decision

Publish complete native Articles adapted from existing Black Scarab reports, with the useful research and illustrations available on X. Supporting launch posts should direct readers to the native X Article. Keep the website in the profile. Avoid a website traffic pitch in launch copy. Retain primary citations for credibility; do not strip evidence to chase an unverified algorithm theory.

Measure follower growth, substantive replies, bookmarks, and available reading/engagement metrics. Premium and native publishing do not guarantee reach. Putting an external link in the first reply is not a proven exemption or a default growth tactic. Any later link experiment should use comparable content and repeated observations without duplicate spam.
